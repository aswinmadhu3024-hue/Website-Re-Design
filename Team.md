### Why did you make these changes?

We made these changes to elevate the site's visual appeal and usability by adding project and team imagery, an interactive canvas hero animation, dynamic event filtering, and a hidden Easter egg that reflects TinkerHub CET's maker culture.

### Key Features
* Interactive Hero Particle Canvas**: A dynamic background rendered via the HTML5 Canvas API that draws moving particle nodes to give the site a futuristic, high-tech entrance.
* Client-Side Event Filtering**: A vanilla JavaScript filtering mechanism that allows users to seamlessly sort upcoming events by categories (*All*, *Hackathons*, *Workshops*) without reloading the page.
* Rich Media Project & Execom Showcase**: Visual card layouts integrated with high-quality project imagery, hover-zoom effects, and custom-bordered avatar profiles for team leads.
* Responsive Mobile Drawer & Hidden Easter Egg**: A fully responsive mobile navigation overlay and an interactive modal pop-up hidden behind the header gear icon for a fun maker-culture touch.

### Technology Used
HTML5: Structured semantic layout for all sections (Hero, Events, Maker Kootam, Execom Team, and Modals).

CSS3 & Tailwind CSS: Utility-first CSS framework (loaded via CDN) providing dark-theme styling, grid layouts, responsive breakpoints, and glassmorphism visual effects (backdrop-blur).

Vanilla JavaScript (ES6+): Powers client-side dynamic event filtering, mobile drawer toggles, modal dialog controls, and canvas animations without relying on heavy external frameworks.

HTML5 Canvas API: Used in JavaScript to render and animate the floating particle background in the Hero section.

Lucide Icons: Open-source vector icon set providing clean UI icons (settings gear, navigation, tags).
